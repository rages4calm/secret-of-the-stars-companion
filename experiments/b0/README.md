# Uninstalled B0 integration prototype

This alternate authored actor module is experimental source under the project's
PolyForm Noncommercial license. It is **not selected by the normal foundation
build**, not installed in the owner game and not a completed B0/wrapping feature.
The existing large/composite/wrapping guards remain in the canonical snapshot.

It adds the two original B0 producer seams to the ordinary observer and joins
checked fixed-slot metadata to the same complete 544-byte staging/DMA/displayed
packet. The existing ROM-free `tools/foundation_large_actor_canary.c/.h` supply
descriptor validation and 16×16 decoding. Original actor activation, guest OAM,
collision, camera and cycle timing are unchanged. Passive hook/transfer counters
distinguish actual interpreter execution from host callback replay.

Build the canonical foundation with your matching owned ROM first, then:

```powershell
python tools/build_experimental_b0.py --base-receipt "<source-build>/source-build-receipt.json" --rom "D:\My Games\Secret of the Stars (USA).sfc"
```

The helper checks the canonical receipt, source and pinned runtime, copies into
a **new** ignored `local/experimental-b0/` folder, and builds there. It preserves
the original build, profiles and ROM. Generated code stays local. Its experimental
receipt cannot be adopted by normal Companion Setup and carries no gameplay
qualification. A successful build does not remove the natural-fixture gap.

New owner authorization permits disposable staged progression. Actual original
parked-B0 loader/constructor execution, opaque margin pixels and cold/rollback
state now pass focused checks on this exact helper candidate. The canonical
module remains unchanged. See the [current staged assessment](../../docs/FOUNDATION-STAGED-PROGRESSION-2026-10-09.md).

The separately checked private candidate passed genuine ordinary guest/DMA and
existing actor/menu/restore proofs, while the two B0 constructors remained
