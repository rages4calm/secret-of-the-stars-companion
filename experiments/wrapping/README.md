## Reproduce the isolated build

First create a canonical matching source build as described in
[BUILDING](../../BUILDING.md). From the repository directory:

```powershell
python tools/build_experimental_b0.py --experiment wrapping `
  --base-receipt local/source-builds/YOUR-BUILD/source-build-receipt.json `
  --rom C:/private/clean-usa.sfc
```

The shared helper validates the canonical48 inputs, matching generated source,
runtime pin and seventeen-file runtime patch. It copies them into a new unique
`local/experimental-wrapping/` directory and substitutes this module there. It
does not overwrite canonical source, a profile or an installed binary. Its receipt
declares `compiled_unqualified_experimental`, `installed=false` and
`matches_authored_snapshot=false`.
