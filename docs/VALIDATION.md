## What the ROM-free source checker checks

The ROM-free checker checks exactly the Git-tracked file set, excludes private
payload paths and binary types, checks recognizable credential formats,
parses Python source, verifies 44 foundation and 13 Companion authored-file
hashes, checks the pinned runtime/patch and verifies nine verbatim notice
hashes. It also checks links in the public entry documents.

The checker does not possess a ROM, game fixtures, saves or audio recordings. It does
not certify gameplay, an entire campaign, native/AOT completion, listening
quality or physical-device input. Historical local reports remain private;
their references in dated development documents are intentionally retained
as provenance, not offered as downloadable public fixtures.

An inactive Actions template is included under `docs/github-workflows/`.
The initial publication token lacks active-workflow upload permission, so this
repository does not currently claim an automated CI pass. The equivalent local
checker passed on the published source set.
