## Implementation

Eight additional runtime patch groups extend source-certified callee instructions,
nested instructions, dynamic processor-status frontiers, architectural returns,
after-call source closure and callable progress. Original producers, scheduler,
stack, live processor mode, bank, interrupts and receiving return ownership remain
authoritative. An unsupported successor stays an original-execution barrier.

Synchronous native callable instructions now use the original invocation's scoped
progress checkpoints, including its actual APU-driving state during cycle charging
and observer callbacks. Nested calls retain the original references and restore
the enclosing callable state. This repairs a source-proved flush partition difference;
it does not change APU arithmetic, clock ratios, thresholds or serialized fields.

The public helper composes 50 ordered patches from verified runtime and SDL donors.
Its emitted 9,883 ordinary rows, 235 task rows and three reset rows describe generated
code, not actual execution coverage or completion of native/AOT conversion.
