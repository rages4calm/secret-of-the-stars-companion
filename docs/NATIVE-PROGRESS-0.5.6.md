# Native 0.5.6 WIP — progress and scope

This release publishes native update 105 / source 134 with the unchanged Companion 0.3.6 launcher. Setup builds the game locally from your owned USA ROM. The package contains authored source, launcher and notices; it contains no ROM, generated game code, extracted assets, saves or playable game binary.

## What improved

The latest native group handles the original town-destruction animation and message returns reached by a late-game laboratory machine. Original loaders, dialogue, story flags, rendering and hardware timing retain ownership. The complete event, aftermath and chapter 21 to 22 transition ran through to idle.

A normal-paced 4,488-frame comparison against the preceding exact build reduced 103 interpreter calls to zero. CPU/master clocks, all compared guest dumps, the full checkpoint and full native DSP audio matched. The tested context used isolated, source-backed staged progression; it was not a natural campaign playthrough.

Separate original-producer checks completed four layouts of the custom-named growing town (chapters 4, 6, 11 and 16) and builder recruitment with zero fallback. The layout samples retained partial staged quest state. The original waterfall-device grant also completed without fallback; it was not counted as a new native conversion.

Five additional original message-return families have source proof for nine typed instruction keys. They remain source-only support, distinct from runtime-tested mechanics. The latest group adds 45 guarded keys at 16 PCs; counts do not establish whole-game coverage.

## Features retained

Optional widescreen scenery and actors, enhanced original pixels and Original View remain available. The full 42-page Guide, automatic Current advice, map/town tracking, keyboard/controller bindings, XP/gold and encounter settings, movement boost and hold/toggle fast-forward are retained. The original ROM, collision and activation behavior remain authoritative. Replacement HD artwork is deferred.

## What remains

Complete native/AOT conversion remains unfinished. Guarded interpreter fallback remains available for unsupported contexts. No whole-game percentage is claimed from code counts or selected zero-fallback scenes. Campaign/story accuracy, long-session behavior and broader controller/hardware coverage still need player feedback.

Compilation and qualification are separate: every fresh build keeps its own immutable `compiled_unqualified` receipt, and focused checks apply only to the exact tested binary. Historical reports retain their original scope. Development checkpoints can be build-specific; backwards save compatibility is not guaranteed.
