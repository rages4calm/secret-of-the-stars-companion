# Native execution continuation — 0.5.5 WIP

October 15, 2026. Native 0.5.5 adds source-owned CPU instruction coverage while retaining Companion 0.3.6 and the existing PC features. Complete native/AOT execution remains unfinished: some execution still uses the original interpreter. No whole-game percentage is claimed.

## What changed

The latest group compiles independently authenticated CPU steps from existing source-selected task graphs. It preserves original producers, task selection, scheduler ownership, call/return decisions, live mode checks, byte guards and fallback. It adds 121 generated ordinary instruction rows; the focused route actually witnesses 37 newly native instruction keys with no fallback among those 37. Generated rows are not campaign coverage.

The full 42-page Guide, 25 automatic Current chapter cards and finer leads, maps, guide-town tracking, configurable controls, XP/gold/encounter settings, movement boost and hold/toggle fast-forward remain. Original ROM data, center/collision/activation/pace, optional Original View and guarded rendering fallback are preserved. Replacement HD artwork remains deferred.

## Exact candidate checks

- One enabled counterpart reuses the retained original coherent town/menu reference: all 116,256 completed CPU/state/clock/bus/open-bus boundaries, 21 guest components and full checkpoint bytes match. No checkpoint bytes, flags, coordinates, PC or status were staged for that menu route.
- Separate finite rendering checks pass 144 independently expected margin pixels. Rendering prerequisites were staged in strict copied checkpoints and original loaders/producers supplied coherent resources; this is not natural acquisition or campaign proof.
- 22 configured keyboard/indexed SDL virtual-pad controls pass, including Current/Guide operation. Actual captures were inspected.
- 300 D3D11/audio frames run at 60.014 FPS with zero steady underflow, missing-frame or audible-drop deltas.
- Copied source-profile Update/Adopt and actual Companion Resume for 60 frames pass. Protected owner settings, saves and selectors remain unchanged. The declared ABI matches 0.5.4; strict compatibility checks still apply.

These are bounded exact-artifact checks, not physical-controller, listening, whole-campaign or full native/AOT certification. Earlier 0.5.4 coldboot/save results do not transfer to this executable. Campaign/story verification belongs to the owner and playtesters and is not an exhaustive release gate.
