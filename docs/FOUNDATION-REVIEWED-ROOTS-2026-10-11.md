## What the reviewed file does

`native/foundation/recomp/reviewed-roots.json` supplies 183 additional exact
PC/M/X/native-E0 analysis seeds with review identifiers and hash-only provenance.
Review checked 359 matching original call-boundary observations, direct call
operands and live entry widths. Nine quarantined observed contexts stay excluded.
The file contains no instruction bytes, generated bodies, memory images, saves,
artwork or inferred callee exits. Its review hashes identify evidence; public
builds do not need private reports or captures to resolve them.

The loader joins these seeds to the standard analyzer's additional-root union.
It does not create CFG function boundaries or force AOT eligibility. Three
data-region directives, three authority-data directives and 42 forced-original
entries retain their previous identities. Unknown modes/calls and registered
pre-opcode hooks remain original-execution boundaries. `00ABD0:M1X1` stays
interpreted because its exit fact is unproved.

With the existing 13 root contexts, the clean-ROM analysis has 196 roots and
245 discovered contexts: **151 full bodies, 93 proved prefixes and one
interpreted context**. A prefix executes only its statically proved instructions
and yields before the unproved call. These are generation dispositions, not
executed campaign percentages or certification of every mode body. Original
instruction, bus, scheduler, stack and return behavior remain required.

## Public build and regeneration

The ordinary helper command needs no profile input:

```powershell
python tools/build_public_foundation.py --rom "D:\My Games\Secret of the Stars (USA).sfc"
```

Reviewed roots and proved prefixes default on. Generation diagnostics may use
`--no-reviewed-roots` or `--no-proven-prefixes`; normal Setup needs neither.
The supported SDK regeneration path forwards the single
`--reviewed-root-manifest` input and `--faithful-prefixes`, with checked ROM
CRC32/SHA-256, `--cfg-roots` and `--no-host-root-scan`. A fresh project emits
`recomp/funcs.h` after game-code generation. A generated header from an older
tree must not be mistaken for an authored input when comparing fresh builds.
See [BUILDING.md](../BUILDING.md) for prerequisites and regeneration scope.

The ninth additive patch, `patches/runtime-reviewed-roots.patch`, adds the
strict metadata reader and interface forwarding in four Python files. It
changes no decoder or runtime instruction semantics. All eight preceding patch
bytes remain exact. Runtime pin remains
`7931b53c4968d9cf3fffeabf3e7f5f21d2ecf3a0`; the nine-patch cache is
`7931b53c4968-d2a52ce241c92ff8`. Its marker and receipt bind all nine ordered
full hashes and resulting source hashes. Previous checkouts are retained.
There are 61 native and 24 unchanged Companion authored inputs. The serialized
checkpoint/SRAM/execution-state ABI remains unchanged; compatible profile
