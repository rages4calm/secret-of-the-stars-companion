# Reviewed analysis roots

This proposed authored configuration contains 183 reviewed native-mode PC/M/X analysis seeds for the clean USA ROM identified by its SHA-256. It supplies discovery inputs to the existing `additional_roots` union. It supplies no game instructions, decoded bodies, assets, save data, captures, function boundaries, callee exit facts, timing overrides or force-native declarations. Users generate derived code locally from their own matching ROM.

Every seed has original call-boundary evidence with live entry widths and native E=0, acceptance by the pinned observation parser, and an existing analyzer result in the qualified reference tree. Review IDs identify the private row ledger; public builds require no private ledger or capture directory. The three `reviewed_against` hashes identify the reference executable, qualification freeze and capture-identity object. They are audit identities, not a claim that the file itself qualifies a new build. The capture identity hash uses UTF-8 sorted-key compact JSON of that identity object.

The schema is exactly `snesrecomp reviewed analysis roots v1`. Top-level fields are `schema`, `rom_sha256`, `mapper`, `module_id`, `reviewed_against` and `roots`. Each row has exactly `pc24`, `m`, `x`, `emulation` and `review_id`. PCs use six uppercase hexadecimal digits; M/X/E use JSON integers, with E=0. Duplicate PC/M/X tuples, unknown fields or versions, unsupported identities, noncanonical/unmapped PCs, data-mask entries and force-LLE entries or their aliases must be rejected. Input links, escaping paths and duplicate JSON keys also require strict loader rejection. Adding a seed must not automatically add its other width modes, LoROM aliases or a CFG `func` boundary.

The review approves discovery, while retaining the analyzer's conservative decisions. Of these 183 seed contexts, 102 are full-body eligible, 80 are prefixes stopping at unproved calls, and `00ABD0:M1X1` remains LLE because its exit fact is unstable. The six existing data directives (three soft `data_region`, three hard `authority_data` intervals) and 42 exact force-LLE entries remain unchanged. Nine observed quarantined contexts remain excluded. Existing architectural/vector/CFG roots retain their own policy.

The reference artifact's finite strict 24-run matrix reports 160 distinct compiled target PCs across its complete discovered tree. For this proposed seed set, 175 mode rows at 141 PCs have a compiled-PC observation; eight rows have none. Those counters do not identify the executed M/X body, and this review does not certify every emitted mode or the full campaign. Original observations, parser admission, analyzer disposition, dispatch registration and runtime execution remain separate evidence layers.

Promotion requires a fresh no-profile generation that preserves the 13 existing root contexts, original masks and exclusions, and reproduces the reference graph, prefix stops and dispatch union. A new compiled artifact then needs its own original-byte, complete guest/packet/art, restore and paced host qualification. The present review performs no generation or native execution and makes no default-policy or installation change.
