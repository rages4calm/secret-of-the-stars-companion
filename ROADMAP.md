# Roadmap

The target is a polished, editable Windows PC edition with attractive original
pixels, true wider scenery/actors, reliable controls/audio and a useful journal.
The port recompiles original instructions through the pinned whole-program
analyzer/emitter and retains original execution where it cannot yet prove a
supported path. Reviewed entry metadata and proved prefixes now broaden that
automatic generation through normal Setup. Complete native/AOT execution
remains a major unfinished task; authored presentation and guidance features
have their own bounded coverage.

The [native 0.4.5 sprite-offset update](docs/FOUNDATION-SPRITE-OFFSETS-WIDESCREEN-2026-10-12.md) adds packet-owned nonzero0471/0473 transforms for compatible ordinary actors/effects. Original terrain, packet, raster and center guards remain; large/travel offsets and ambiguous layouts retain fallback.

The [native 0.4.4 effect rendering update](docs/FOUNDATION-VARIABLE-EFFECT-WIDESCREEN-2026-10-12.md) adds a bounded original variable-effect path in the widescreen margins. Original descriptors resolve the pieces; completed packet and displayed-resource checks own the added pixels. Unsupported anchors, offsets and layouts retain fallback.

The [native 0.4.3 presentation bundle](docs/FOUNDATION-GUIDE-TRACKING-WIDESCREEN-2026-10-12.md) implements guide town tracking, broader ordinary wrapped-map actor rendering and an original invulnerability display. Human testers verify campaign behavior; focused developer checks cover implementation and rendering.

The [native 0.4.2 instruction update](docs/FOUNDATION-MEMORY-RMW-2026-10-12.md) adds all24 supported memory increment/decrement, shift/rotate opcodes and accumulator increment/decrement. Two finite executions retain identical state and clocks with 263 newly native instructions in the sampled window; separate guide/combat rendering and paced audio pass. Companion remains 0.3.6. The [0.4.0 story guide](docs/FOUNDATION-STORY-GUIDE-2026-10-12.md) contains 42 pages in 14 sections through the ending. Owner and play testers verify campaign directions; developer checks focus on implementation, rendering and reported failures.

Full native/AOT execution, broader story/party/effect rendering and hardware coverage remain unfinished. Guide coverage does not establish automatic campaign event detection, permanent quest history or new objective pins. Current original execution and guarded renderer fallback remain authoritative.

## 1. Public first-run setup and packaging

Companion now connects ROM selection/validation, source-build progress and
cancellation, isolated profile adoption, explicit compilation status, title-first
launch and selected copied-save resume. Public Play no longer requires private
fixture/checkpoint data. XP/gold rates, guarded movement boost and keyboard/
controller hotkeys are editable in the launcher. Companion 0.3.5 adds an ordinary random encounter modifier alongside rewards and travel; Original View uses the original 100% check without rewriting the saved choice.
The [WIP release](https://github.com/rages4calm/secret-of-the-stars-companion/releases) now provides a ROM-free launcher/source ZIP, checksum and version manifest. Users still need their owned ROM and the documented development tools to build the game locally.
Source-profile updates now create verified new folders and retain old profiles
for selection-only rollback. A source-first package tool includes one
self-contained GUI, authored source and notices; native game and original data
stay excluded. Finish broader package/hardware checks and automatic GUI release
updates. Configured profile roots currently retain absolute paths.
Normal Setup now reproduces the reviewed expanded analysis using the authored
entry metadata; it needs no private gameplay recordings. Do not distribute
the ROM or generated game code.

## 3. Story guide and current advice

The full written story guide is implemented: 42 pages / 14 sections from David and the first StarCrest through the final battle and ending. It includes separate-party prerequisites, town settlers, warehouse transfers, Kustera shrine components and cooperative final mazes. Select switches Current / Guide; the configured directional game buttons browse pages and sections, and Game B closes. J / left-stick click remains the configurable journal opener.

The suggested section uses original current chapter 0-24, with selected earlier starting pages. This is a navigation aid, not precise automatic event detection. Browsing does not write guest progression or remember future completion after rollback. Game X separately selects a named guide town for the map. Current fine advice retains the original source/state predicates already verified in the [Kaja/Bonzley continuation](docs/FOUNDATION-KAJA-BONZLEY-2026-10-12.md). Read the [guide sources and coverage limits](docs/JOURNAL-GUIDE-SOURCES.md).

The owner and play testers verify campaign directions. Implement useful corrections from their reports without making exhaustive developer campaign replay a prerequisite for each content change. Additional automatic event-specific advice and objective pins still require original source/state evidence; possession, current party and permanent completion remain distinct. Durable quest history is future work and would need defined reset/load/rewind semantics.

The navigation map retains original area terrain, player position, towns and independently qualified destinations. Wider map/story rendering, two-party town changes and effects remain separate work. Game X explicitly tracks towns named on mapped guide pages using original entrance coordinates. No guessed route pins or exploration history are added.

## 4. Audio and presentation polish

Companion 0.3.3 adds exact Auto/720p–4K window selection and original CRT/square-pixel/square-frame shape controls, preserving custom values and unrelated settings. The installed modal/audio repair uses genuine guest DSP prefill and one-shot keyboard rewind requests; nine modal routes pass. Separate pacing qualifies 15 distinct routes in 19 attempts: 13 passed initially, then the two failed routes and two controls passed unchanged-artifact repeats. Initial failures remain retained without an inferred cause. Extend finite scene/cutscene coverage and complete the separately recorded ROM-free package stage.

Keep enhanced original pixels and experimental widescreen moving toward a
consistent whole-game presentation. A replacement HD world/sprite pack is
deferred. Optional finer menu-frame art has only bounded coverage.

## 5. Continue automatic native execution

Extend the standard analyzer and faithful backend from authentic original
entry/mode evidence. Preserve hard data exclusions, unknown-call returns,
registered producer hooks, original instruction/bus timing and complete
checkpoint equality. Qualify new supported contexts with original/native
comparisons across both parties, town changes and story transitions. The
current generated contexts, prefixes and 18 continuation certificates describe
generation only;
full game execution and the remaining backend/refusal cases are still open.

## 6. Player testing and focused developer checks

The owner and play testers verify the campaign, navigation directions, party
progression and evolving town during play. Report a checkpoint context and the
incorrect step when possible. Developers implement corrections and run focused
rendering, input, restoration and playback checks on protected copies.

Physical controller variation, listening, long sessions and broad story/effect
coverage remain open. A manually complete guide and player-selected marker do not certify full campaign
execution or every renderer context. Keep observed failures and tested coverage
separate, and preserve owner data.
